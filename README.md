# Scout

Scout é uma plataforma de monitoramento de servidores e bancos de dados desenvolvida com FastAPI.

## Objetivos

- Monitorar servidores Linux e Windows
- Monitorar bancos MySQL e PostgreSQL
- Coletar métricas de CPU, RAM e Disco
- Gerenciar múltiplos clientes
- Dashboard para visualização em tempo real
- Sistema de alertas

## Tecnologias

- Python
- FastAPI
- SQLAlchemy
- MySQL
- Redis
- Docker
